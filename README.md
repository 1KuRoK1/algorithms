# Алгоритмы — контрольные работы 1–3

Решения задач на C# (.NET 8). Все алгоритмы и структуры данных реализованы вручную (без `Array.Sort`, `Dictionary`, `List<T>` и т.п.), в соответствии с требованиями контрольных работ.

## Требования

- **.NET SDK 8.0** — [скачать](https://dotnet.microsoft.com/download/dotnet/8.0).
- Проверить установку: `dotnet --version` → должно вывести `8.x.x`.

## Как запустить любую задачу

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/1KuRoK1/algorithms.git
   cd algorithms
Перейдите в папку нужной задачи (например, задача 11 КР2):

bash
cd kr2/Task11
Запустите:

bash
dotnet run
Программа попросит ввести данные (формат — из условия задачи). После ввода последней строки — сразу выведет ответ и завершится.

Замечание: для задач, где ввод может быть в одну строку или по одному числу в строке (Task11, Task21), оба варианта работают. Для задач с файловым вводом (INPUT.TXT) — формат указан в условии.

Режим Release для больших N
Для задач с N до 10^8 (КР3 Task1) и до 6·10^7 (КР1 Task16) рекомендуется запуск в режиме Release — это ускоряет выполнение в 2–3 раза:

bash
dotnet run -c Release
Структура проекта
Каждая задача — отдельный проект .NET:


Task11/
├── Task11.csproj   ← описание проекта (target framework, настройки)
└── Program.cs      ← весь исходный код
Отдельный .sln не требуется: dotnet run работает с .csproj напрямую.
