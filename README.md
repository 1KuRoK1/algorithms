# Алгоритмы — контрольные работы 1–3

Решения задач на C# (.NET 8).

## Как запустить

1. Установите .NET SDK 8.0: https://dotnet.microsoft.com/download/dotnet/8.0
2. Клонируйте репозиторий: git clone https://github.com/1KuRoK1/algorithms.git

3. Перейдите в папку нужной задачи и запустите:
cd kr3/Task17
dotnet run
